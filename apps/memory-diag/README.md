# memory-diag · MemOS 检索异常诊断页

自包含（零依赖、无构建步骤）的静态诊断报告页，把 2026-08-17 对
`/product/search` 返回空结果问题的链路追踪可视化：写入链路、检索链路故障点、
两个坏节点、时间线、复现实验、修复方案、查看全部记忆的方法。

## 运行

```powershell
# 方式一：本地静态服务（推荐）
cd D:\project-memo\MemOS\apps\memory-diag
python -m http.server 8090
# 打开 http://127.0.0.1:8090/

# 方式二：直接双击 index.html（复制按钮等功能在 file:// 下可能受限）
```

## 说明

- 页面为**静态快照**，所有数字来自本地实测（Neo4j / Qdrant / API 真实查询）。
- 顶栏的「API 探测」会尝试请求 `http://127.0.0.1:8000/health`；
  浏览器跨域（CORS）默认放行名单不含本页来源，若探测受限，
  可在 MemOS `.env` 配置 `CORS_ORIGINS=http://127.0.0.1:8090` 并重启 API 后启用实时模式。
