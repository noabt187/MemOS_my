# 两轮事件信息测试：预期结果

> 这个文件只用于对照结果，不要导入MemOS。实际需要导入的是同目录下的 `case-input.md`。

## 测试目的

这个案例用于检查四件事：

1. 第一轮能否从原文提取人物关系和事件候选信息。
2. 第二轮能否重新参考原文，把碎片合并成两条完整事件并补齐 `info`。
3. 已完成的聚餐和计划中的羽毛球不能被合并成同一个事件。
4. `source_recorded_at` 是文件导入时间，不能覆盖原文中的事件时间。

## 允许的记忆数量

合理结果是两条事件记忆，并更新一条“林誉恒”的联系人记忆。模型措辞可以不同，但事实不能改变。

### 联系人更新：人物关系

自然语言记忆应接近：

```text
林誉恒是用户的大学同学。
```

这不是一次具体事件，因此不能单独写入事件记忆。它应更新“林誉恒”的联系人记忆：

```json
{
  "record_type": "person_relationship_summary",
  "person_name": "林誉恒",
  "relations": ["college_classmate"]
}
```

### 事件记忆一：已经完成的聚餐

自然语言记忆应接近：

```text
2026年8月18日18点30分，用户和林誉恒在杭州市滨江区星光大道的渔火餐厅吃晚饭，目的是庆祝用户完成期末项目；晚饭约在20点10分结束。
```

对应的 `info` 应接近：

```json
{
  "record_type": "event",
  "assertion_basis": "explicit_single",
  "event_type": "dining",
  "event_status": "completed",
  "event_actor": "用户和林誉恒",
  "event_action": "吃晚饭",
  "event_target": null,
  "participants": ["用户", "林誉恒"],
  "event_location": "杭州市滨江区星光大道渔火餐厅",
  "event_time": "2026-08-18 18:30 至 20:10",
  "event_time_text": "昨晚18点30分，20点10分左右结束",
  "source_recorded_at": "实际导入该Markdown文件的时间"
}
```

允许 `event_actor` 只写“用户”，但 `participants` 必须同时包含用户和林誉恒。

“庆祝用户完成期末项目”必须合并在这条聚餐记忆的自然语言正文中，不能另存成“此次聚餐是为了……”的孤立记忆。

### 事件记忆二：计划中的羽毛球训练

自然语言记忆应接近：

```text
用户和林誉恒计划于2026年8月25日19点在滨江体育馆3号场打羽毛球，为下个月的校赛进行训练准备。
```

对应的 `info` 应接近：

```json
{
  "record_type": "event",
  "assertion_basis": "explicit_single",
  "event_type": "sports",
  "event_status": "planned",
  "event_actor": "用户和林誉恒",
  "event_action": "打羽毛球",
  "event_target": null,
  "participants": ["用户", "林誉恒"],
  "event_location": "滨江体育馆3号场",
  "event_time": "2026-08-25 19:00",
  "event_time_text": "下周二，也就是2026年8月25日晚上19点",
  "source_recorded_at": "实际导入该Markdown文件的时间"
}
```

“为下个月的校赛进行训练准备”必须合并在这条羽毛球事件的自然语言正文中，不能另存成“此次约定是为了……”的孤立记忆。

## 判定通过

满足下面条件即可认为效果通过：

- 生成一条已完成的聚餐事件。
- 生成一条计划中的羽毛球事件。
- 两条事件没有被错误合并。
- 聚餐时间解析为2026年8月18日，而不是文件导入时间。
- 羽毛球时间解析为2026年8月25日19点。
- 两条事件的参与者都包含“用户”和“林誉恒”。
- 人物关系没有被错误标记成具体事件，而是更新到联系人记忆。
- 没有生成“此次聚餐”“这次约定”“20点10分结束”等无法独立理解的碎片记忆。

## 判定失败

出现以下任意情况，应认为仍有问题：

- 把聚餐和羽毛球合并成一条记忆。
- 把文件导入时间当成聚餐时间。
- 把已经完成的聚餐标记为 `planned`。
- 把尚未发生的羽毛球训练标记为 `completed`。
- 聚餐地点和羽毛球地点发生串线。
- 第二轮生成了原文中不存在的人物、地点或目的。
